# Внешняя обработка "Загрузка погоды" (API Open-Meteo)

Внешняя обработка для 1С, демонстрирующая интеграцию с внешним веб-сервисом через HTTP-запросы и парсинг JSON.

## Что делает
1. Отправляет GET-запрос к открытому API `api.open-meteo.com` с параметрами координат (Москва).
2. Получает ответ в формате JSON.
3. Извлекает вложенные данные о текущей температуре и скорости ветра.
4. Выводит результат в таблицу на форме.

## Технические особенности
*   **Передача параметров:** Демонстрируется передача параметров прямо в строке URL-запроса (`?latitude=...&longitude=...`).
*   **Разбор вложенного JSON:** Данные извлекаются из вложенного объекта `current_weather`.
*   **Безопасность:** Реализована обработка исключений (`Попытка... Исключение`). Если сайт недоступен или прислал неверный формат данных, программа не вылетает с критической ошибкой, а выводит понятное сообщение пользователю.
*   **Управление ресурсами:** Поток `ЧтениеJSON` корректно закрывается в любом случае.

## Как запустить
1. Скачайте файл `.epf` из папки `build`.
2. В 1С выберите меню **Файл -> Открыть...**
3. Выберите скачанный файл и нажмите кнопку «Узнать погоду».
