# Внешняя обработка "Загрузка курсов валют" (API + JSON)

Внешняя обработка для 1С:Управление торговлей 11, демонстрирующая интеграцию 1С с внешними веб-сервисами.

## Зачем это нужно
Бухгалтерам и менеджерам часто требуется актуальная информация о курсах валют. Ручной ввод данных занимает время и приводит к ошибкам. Обработка позволяет получить курсы доллара и евро из открытого API Центробанка РФ в один клик.

## Что делает
1. Отправляет HTTP-запрос к API ЦБ РФ (`cbr-xml-daily.ru`) с использованием защищенного соединения (HTTPS).
2. Получает ответ в формате JSON.
3. Парсит JSON-строку средствами платформы 1С (`ЧтениеJSON`).
4. Выводит полученные курсы валют в таблицу на форме.

## Как запустить
1. Скачайте файл `.epf` из папки `build`.
2. В 1С (в режиме «1С:Предприятие») выберите меню **Файл -> Открыть...**
3. Выберите скачанный файл.
4. Нажмите кнопку «Загрузить курсы».

## Технические детали
- Использовано клиент-серверное взаимодействие (кнопка на клиенте, запрос на сервере).
- Для работы по HTTPS применен объект `ЗащищенноеСоединениеOpenSSL`.
- Реализован механизм обработки исключений (`Попытка... Исключение`) на случай отсутствия интернета.
- Исходный код модуля формы находится в папке `src`.
